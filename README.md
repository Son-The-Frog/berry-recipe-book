# Berry Recipe Book

This is a digital book where I can keep track of my favorite berry recipes, so I remember exactly how many flies are needed for the Sunny-Day Berry Mix-up!

## Features
- Cozy berry-themed colors
- Interactive recipe cards that expand when clicked
- My secret berry and fly recipes
- Ability to add new recipes directly in the browser
